# 飞书询盘卡片按钮设置卡（15 分钟）

> 目标：运营在飞书「运营询盘」群里看到新询盘卡片，直接点「✅ 已跟进 / 💰 成交 / ❌ 无效」，
> 状态自动回写 Bitable leads 表 + 自动记一条跟进日志——全程不离开飞书。
>
> 原理一句话：群自定义机器人（FEISHU_BOT_WEBHOOK）只能发不能收；按钮回调必须走
> **自建应用**（就是现在登录后台用的那个飞书应用）的「卡片回调」。

---

## 你要做的 5 步（只有你能做）

全部在飞书开放平台后台操作：<https://open.feishu.cn/app> → 选我们的自建应用。

### Step 1 · 加两个权限（权限管理）

左侧「权限管理」→ 搜索并勾选：

| 权限 scope | 作用 |
|---|---|
| `im:message` | 读/更新群里的卡片消息（点按钮后把卡片改成「✅ 已由 xx 标记为…」） |
| `im:message:send_as_bot` | 以机器人身份往群里发消息（回写失败时的中文报错提醒） |

### Step 2 · 拿 Encrypt Key 和 Verification Token（事件与回调 → 加密策略）

左侧「事件与回调」→「加密策略」标签页：

1. **Encrypt Key**：点「重置/查看」会显示一串字符 → **复制保存**
2. **Verification Token**：同页 → **复制保存**（可选校验，建议也配上）

### Step 3 · 把机器人拉进「运营询盘」群

在飞书群里：群设置 → 机器人 → 添加机器人 → 选我们的自建应用机器人。
（不加群的话按钮推送不到这个群，回调卡片也发不出去。）

### Step 4 · 配卡片回调地址（事件与回调 → 回调订阅）

左侧「事件与回调」→「回调订阅」标签页 → 「消息卡片回调」（或叫「卡片回传交互」）：

1. 订阅方式选「**将回调发送至开发者服务器**」（不要选长连接）
2. 请求地址填：

```
https://YOUR-OPS-BOARD.vercel.app/api/feishu/card
```

3. 点保存——飞书会立刻发一个 challenge 请求验证地址。
   **前提：Vercel 上最新代码已部署且两个环境变量已配好（Step 5），否则握手会失败。**

### Step 5 · 发版（版本管理与发布）

改权限后必须发版才生效：左侧「版本管理与发布」→「创建版本」→ 填版本号（如 1.1.0）
→ 提交发布 → 等管理员审核通过（企业自建应用一般自己就是管理员，秒过）。

---

## 需要改代码/配置的步骤

在 你的 Vercel 项目（ops-board）配环境变量（Production）：

| 变量 | 值 | 作用 |
|---|---|---|
| `FEISHU_CARD_ENCRYPT_KEY` | Step 2 的 Encrypt Key | 验签：确认按钮回调真是飞书发的（没配 = 回调一律 403 关死） |
| `FEISHU_CARD_VERIFICATION_TOKEN` | Step 2 的 Verification Token | 配回调地址时的二次校验（可选但建议） |
| `FEISHU_NOTIFY_CHAT_ID` | 「运营询盘」群 chat_id（`oc_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx`） | 让**三个站点**改用自建应用机器人发卡（webhook 发的卡片按钮收不到回调） |

> ⚠️ `FEISHU_NOTIFY_CHAT_ID` 同时要在**三个站点的 Vercel 项目**（vape-dubai / vape-gulf /
> vape-europe）里配上，站点代码也有一次小同步（卡片加按钮 + 优先走应用机器人推送），
> 该步骤涉及代码改动，由你的开发人员按本卡说明操作。
>
> ⚠️ 白名单：只有 `ADMIN_OPEN_IDS` 里的 open_id 点按钮才生效（其他人点了只提示
> 「无权限」）。运营的 open_id 确认已在这个名单里。

## 验收（按顺序 3 分钟）

1. 在任意站点提交一条测试询盘（或等真实询盘进来）
2. 「运营询盘」群收到卡片，**下方有三个按钮**：✅ 已跟进 / 💰 成交 / ❌ 无效
3. 点「已跟进」→ 立即弹 toast「⏳ 正在标记为「已跟进」…」→ 几秒内卡片按钮区变成
   「✅ 已由 Admin 标记为「已跟进」 · 时间」
4. 打开 Bitable leads 表：那条询盘「状态」= 已联系；followups 表多一条
   「飞书卡片标记为「已跟进」」
5. 再点一次同一张卡（或飞书重推）→ 不会重复写，note 变「状态已是…，本次点击未重复写入」

## 状态映射（写死的）

| 按钮 | Bitable「状态」变成 |
|---|---|
| ✅ 已跟进 | 已联系 |
| 💰 成交 | 成交 |
| ❌ 无效 | 流失 |

## 出问题了看哪里

- 点按钮弹「无权限」→ 你的 open_id 不在 `ADMIN_OPEN_IDS`，把 open_id 发我加进去
- 点按钮弹「回写失败…」→ 群里会有中文报错卡，截图发我（Vercel 日志同步可查）
- 配回调地址时提示握手失败 → 确认 Vercel 已部署最新代码 + `FEISHU_CARD_ENCRYPT_KEY` 已配
- 卡片根本没有按钮 → 站点代码还没同步按钮 patch，或站点还走旧 webhook 推送
